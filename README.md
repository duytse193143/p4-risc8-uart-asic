# P4 Project: RISC8 CPU + UART — RTL to GDSII on Sky130

An 8-bit RISC CPU with a memory-mapped UART, built from an empty folder and taken
through the full ASIC flow — simulation, synthesis, STA, LEC, gate-level simulation,
floorplan, placement, CTS, routing, DRC, LVS and GDSII — using only open-source tools
(Icarus Verilog, Yosys, OpenSTA, LibreLane 3.0.17) on the SkyWater **Sky130** PDK.

After reset the chip prints `OK!` on `uart_tx`, then echoes every byte it receives on `uart_rx`.

**Result: `P4 SIGNOFF: ALL TARGETS MET`**
📄 **Full project report:** [docs/Project4_RISC8_UART_ASIC_Report_TranDuy.pdf](docs/Project4_RISC8_UART_ASIC_Report_TranDuy.pdf)

## The design

| Item | Value |
|---|---|
| Pins | `clk`, `rst_n`, `uart_rx`, `uart_tx`, `halted` |
| Clock | 200 MHz (5 ns) |
| CPU | 8-bit, 16 instructions, 8 registers (r0 = 0), 3 clocks per instruction (FETCH / DECODE / EXECUTE) |
| Memory | 52-instruction program ROM (logic), 16-byte data RAM (flip-flops) |
| UART | 115200 baud, 8N1, `CLKS_PER_BIT = 1736`, 2-flip-flop synchronizer on RX |

**Memory map**

| Address | Name | Access | Meaning |
|---|---|---|---|
| 0x00–0x0F | RAM | R/W | 16 bytes of data RAM |
| 0xF0 | TXDATA | W | send this byte on `uart_tx` |
| 0xF1 | STATUS | R | bit0 = tx_busy, bit1 = rx_valid |
| 0xF2 | RXDATA | R | received byte (reading clears rx_valid) |

### Synthesis and pre-layout timing (tt corner, 200 MHz)

| Item | Result |
|---|---|
| Chip area (Yosys 0.62) | 14,139.8 µm² (305 flip-flops: 174 `dfrtp`, 3 `dfstp`, 128 `edfxtp`) |
| Setup WNS / TNS | **+1.313 ns** / 0 |
| Hold WNS / TNS | **+0.115 ns** / 0 (worst path: `rx_meta → rx_sync`) |
| Jitter tolerance (STA sweep) | setup fails above ~1.56 ns uncertainty, hold above ~0.365 ns |

| Item | Result | Target |
|---|---|---|
| Setup worst slack | **+0.852 ns** | ≥ 0 |
| Hold worst slack | **+0.308 ns** | ≥ 0 |

## How to run

Environment: Windows 11 + WSL2 (Ubuntu 26.04) + Docker Desktop + LibreLane 3.0.17 (`~/ll-venv`).

```bash
# In Ubuntu, project folder
make sim            # RTL simulation          -> TEST PASSED
make sim_jitter     # jittery-clock simulation -> TEST PASSED

# In the tool shell: source ~/ll-venv/bin/activate && librelane --dockerized
bash scripts/run_synth.sh       # synthesis   -> results/, reports/synth_stat.txt
bash scripts/run_sta.sh         # STA         -> TIMING MET at 200 MHz
bash scripts/run_sta_jitter.sh  # jitter sweep
bash scripts/run_lec.sh         # LEC         -> LEC PASSED
bash scripts/run_gls.sh         # GLS         -> TEST PASSED

# Back in Ubuntu, venv active
make flow           # full RTL-to-GDSII run (~5 min) -> runs/RUN_<date>/
make summary        # -> P4 SIGNOFF: ALL TARGETS MET
```

## Notes

- Numbers differ slightly from the course reference run (setup +1.026 ns pre-layout,
  14,122 µm²) because the LibreLane container ships a newer Yosys (0.62).
- On this machine the PDK was installed under
  `~/.ciel/ciel/sky130/versions/<hash>/sky130A`; a symlink `~/.ciel/sky130A` points to it
  so the scripts find the liberty file.
- `runs/`, `sim/` and `lib/` are not committed (large or regenerated by the scripts).
